    How file-only extraction works

    Upload one or more files. The app separates explicit study ID headings and dated notes, then extracts supported observations and their evidence. You do not type patient information, dates, shifts, event counts or item codes.

    Use View source results to inspect an observation. Export selected PDF opens the print dialog: choose Save as PDF. The seven-page report follows the original PREMII sections and four-column layout. When a shift is not documented, it is labeled as an observation rather than assigned a shift number.

    Not found in source means no supported evidence was extracted. It does not mean normal, zero or No. Conflicting explicit codes remain unresolved. Reports use source note scope when true shift boundaries are unavailable; they must not be treated as validated per-shift measurements.

    Records stay in tab memory and disappear on refresh or close. JSON/CSV include evidence and missingness statuses. The original documents are not included in exports or uploaded to a server.

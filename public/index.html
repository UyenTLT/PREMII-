About this questionnaire

Based on the supplied English PREMature Infant Index Questionnaire (PREMII™) and the codebook “PREMII 建立資料用”. The Traditional Chinese interface is a development translation, not an officially validated version.

Select one response per support domain. For low-flow respiratory support, record source and flow, and skip OA. If no feeds occurred, skip FEED1. Device and feeding-method details are supplemental and unscored. The supplied documents contain no total-score algorithm.
